# Stage 2A — External Plan Encoder + Independent Plan Decoder（300 步 Pilot）报告

**判定：PASS（有条件）。**
- 文字 Plan 被压成 8 个连续 latent 后，确实保留了**与这道题相关、可被读取**的信息。
- 在没见过的 Plan 上，正确 Z 稳定、显著地优于打乱 Z、均值 Z 和零 Z。
- 同题 A/B 两个 Plan，在 CE 上全部可区分（8/8）。
- 但**方法级**的自由生成恢复只是部分成功：held-out 8 对中只有 3 对清楚切换；具体式子和数字基本是编出来的。

本实验只说明 Plan → Z 的信息保留和可读性，**不说明** Qwen3-4B Executor 会使用 Z（那是 Stage 2B 的问题），也**不说明**只看 Question 能生成 Z（Stage 2C）。

**自由生成（验证集 40 条，free-run）：**
- **正确 Z**：40 条生成各不相同；把生成与 40 条参考 Plan 比对，**25/40 最接近的就是自己的 Plan**（随机为 1/40）；token F1 0.50；方法词召回 0.39。
- **打乱 Z**：0/40 接近自己的 Plan，**25/40 最接近提供 Z 的那条 Plan（donor）**，说明生成内容由 Z 决定。
- **均值 Z / 零 Z**：10 条输入都生成**同一段**固定模板，方法词召回为 0。
- **latent 几何**：验证集跨 Plan 的 raw cos 为 0.45，相对跨 Plan 标准差为 0.74，没有塌缩。

## 同题双 Plan（核心）

- **held-out 8 对**：Δ 均值 0.110 [0.071, 0.157]；16 个 Δ 全部为正，**8/8 对两边都为正**。
- **扩展 20 对**：Δ 均值 0.092 [0.067, 0.118]，18/20 对两边都为正。
- **只看方法/子目标类 token 时信号弱很多**：held-out 平均 Δ 只有 0.040，8 对中有 4 对的 B 方向为负。所以 A/B 的区分有相当部分来自 Plan 的结构和措辞，而不全是方法本身。
- **自由生成（人工判定，详见 `evaluations/heldout_plan_generations.md`）**：
  - **清楚切换 3/8**：00336（Lagrange vs 不等式法）、00574（因式分解 vs 试值）、00486（等差余弦公式 vs 单位根）。
  - **只恢复一侧或部分恢复 4/8**：00569、00507、00305、00479。
  - **失败 1/8**：00309。
  - 按单个 Plan 计：8/16 清楚恢复方法，另有 3/16 部分恢复。
  - 自动判定（生成更接近 P_A 还是 P_B）：held-out 4/8，28 对 14/28。
- **失败模式**：恢复的是方法和步骤结构，题目细节基本是编的（例如 00574 编出 x^y+y^x=2016）。Decoder 看不到题目，这一点在意料之中。

## 改写稳定性（6 条人工改写）

- 5/6 条改写后的 Z 比另一个 Plan 的 Z 更接近原 Z。
- 从改写 Z 生成，4/6 保留了原方法。

## 局限

- 只训练了 300 步：训练 CE 0.67，验证 CE 0.92，有差距，但验证 CE 仍在持续下降（1.00 → 0.94 → 0.92）。
- 同题双 Plan 只有 8 对 held-out（加 20 对扩展），统计功效小。方法判定由我人工完成，没有第二人复核。
- 编码器读的是完整 Plan 文本，Z 可能部分编码了措辞而非抽象方法；方法/子目标 token 上较弱的信号支持这种担心。
- 评测集只做了精确匹配查重，没有检测近似重复。
- 任务书中的配置有三处调整，已在 `configs/actual_run.yaml` 记录：
  - 长度上限 192 → 288（否则会过滤 28% 的样本）；
  - 单卡（micro 8 × 累积 4，全局 batch 仍为 32）；
  - 编码器输入做了按维度标准化（统计量只用训练集），因为之前已发现第 27 层的离群维会让下游塌缩。

## 四个问题

1. **Plan 被压成了 8 个含可读信息的 latent token：是。**
   - 验证集上，打乱 Z 比正确 Z 的 CE 高 0.40 [0.38, 0.43]，300/300 为正；前 32 个 token 上高 0.92。
   - 自由生成在 40 条中有 25 条能找回自己的 Plan；打乱 Z 时生成跟着 donor 走；均值 Z 和零 Z 只出模板。
2. **在没见过的问题上，正确 Z 显著优于打乱 Z 和均值 Z：是。**
   - 逐样本比较：对打乱 Z 300/300 为正，对均值 Z 300/300 为正，对零 Z 299/300 为正（见上表的 CI）。
3. **同题 Plan A/B 在 CE 上可区分（8/8），方法级恢复只是部分成功。**
   - 自由生成清楚切换 3/8；失败例子是 00309（两边都没恢复）和 00305（两边都走代入）。
   - 只看方法类 token 时，Δ 偏弱，且有一半 B 方向为负。
4. **下一步：PASS（有条件），可以进入 Stage 2B。** 但建议：
   - Stage 2B 同样用同题双 Plan 的 margin 和自由生成判定；
   - 可选择先花少量成本改进编码端的方法信息（例如更多同题多 Plan 数据，或在评估中加强方法 token）。
   - 是否推进由用户决定，本次没有自动执行任何后续阶段。
